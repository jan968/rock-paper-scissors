# rock-paper-scissors

This is my Rock Paper Scissors project from The Odin Project Foundations course.

The game is played against the computer in the browser console. You choose rock, paper or scissors, the computer picks randomly and the game keeps score over five rounds.

## What I Practiced

While working on this project I practiced:

- Functions and return values
- Function parameters and arguments
- Conditionals
- Loops
- Scope
- Keeping track of scores
- Working with strings and template literals

The biggest part of this project for me was figuring out how the different functions should work together and where the score variables should live.

## How to Play

Open the page in your browser and open the developer console.

The game will ask you to choose rock, paper or scissors five times. After the last round, the final score and winner are shown in the console.
